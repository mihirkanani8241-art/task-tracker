
# Task Tracker CLI

A command-line task management application built using Python.

## Features

- Add tasks
- Update tasks
- Delete tasks
- Mark tasks as in-progress
- Mark tasks as done
- List all tasks
- Filter tasks by status
- JSON-based data storage

## Requirements

Python 3.10+

## Usage

```bash
python main.py add "Learn Python"
python main.py list
python main.py update 1 "Learn Advanced Python"
python main.py mark-in-progress 1
python main.py mark-done 1
python main.py delete 1
```

## Storage

Tasks are stored locally in tasks.json.
